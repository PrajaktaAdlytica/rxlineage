The validation plan

Document the baseline.
Blind the comparison.

  1. 01Interview buyer, operator and oversight owner separately.
  2. 02Record current triage, cohort, baseline window and review-time method.
  3. 03Validate data rights and the pharmacist reference dataset.
  4. 04Score a blinded retrospective set at the same queue capacity.
  5. 05Agree thresholds, ownership and stop rules before silent mode.

Primary metric

Pharmacist-adjudicated precision at a prespecified queue size

Relevant adjudicated surfaced cases÷K reviewed cases

Fix K, the case/flag unit and relevance criteria in advance. Report incomplete adjudications, sample size and uncertainty separately.

Include cases outside the queue, abstentions and critical reference cases when assessing missed discrepancies.

Guardrails

Precision cannot hide the cases left out.

Missed critical cases

Critical reference cases not surfaced in the agreed window; retain a critical-case denominator.

False-alert burden

Non-relevant flags per agreed episode or reviewer-workload unit.

Review time

Compare with the baseline using an agreed start/stop method and distribution.

Supporting coverage

Track abstention, missing sources, unresolved reviews and adjudicator disagreement.

Stop rule: Stop or reposition if critical cases are missed or incremental precision over existing history/EHR alerts does not justify pharmacist effort. Record the trigger, reviewer, decision and next action.

Separate conversations

Ask the people who own each part.

Buyer

What would make the evaluation worth funding? Who approves budget? What would disqualify it?

Operator & champion

Which sources arrive late or disagree? How do you reject a flag? What extra burden would be unacceptable?

Oversight owner

Who defines criticality? Which data and security approvals are needed? Which result must stop the evaluation?
