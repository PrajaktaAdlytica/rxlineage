The conceptual object model

Six objects. No drug-change action.

01

Episode

A synthetic admission/discharge reconciliation context.

02

Source record

Observed date, received date, source ID and version.

03

Discrepancy flag

Reason, source references and uncertainty.

04

Reviewer

An identified fictional pharmacist role and next action.

05

Adjudication

A manual disposition, reason and attributed event.

06

Override

An appended correction with the prior event retained.

Permission is part of the design

Keep the source.
Respect the boundary.

Source access does not imply the right to ingest, retain or reuse it. A future pilot needs agreed input contracts, reviewer roles, permission states and exception criteria.

  • Bounded export and integration rights
  • Defined retention and correction rules
  • Named data, safety and security owners
  • Human approval before any external action
